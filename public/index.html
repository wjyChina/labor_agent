连接与配置

在项目根目录的 .env 中配置 API，修改后重启服务。

LABOR_API_KEY=你的 DeepSeek API Key
LABOR_BASE_URL=https://api.deepseek.com
LABOR_MODEL=deepseek-flash
LABOR_CACHE_MODE=local

DeepSeek 使用本地历史续传 Responses API；支持服务端会话的网关可配置 previous_response_id。Bash 以当前系统用户的权限执行命令。
